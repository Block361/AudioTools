    NETWORK ENDPOINTS

    Connect another device

    Run one OpenAoIP device process on each computer. Each device registers its sending and receiving channels automatically; connect them here in the routing matrix.

    Copy the Windows package to the other computer, open a terminal in its folder, and run:

    
    
    Use a different ID for every device, for example stage and foh. Hardware mode uses the default input/output and one stereo pair each. For a mono microphone on channel 1, add --capture-map 1,1. Persistent JSON configurations are included in the examples folder.
    
    
    Allow controller TCP 3210 (or its configured port), receiver UDP 5004 and monitor TCP 5100 on your trusted LAN. Test mode allocates endpoint ports automatically. Audio travels directly between devices.
